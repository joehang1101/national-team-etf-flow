# 特征提取与状态摘要

## 页面怎样阅读

首页按“状态→关键数字→按需展开证据”阅读。单独的signals.html承载七类特征、逐只候选、最近60日状态和标准化示例；回归与身份证据仍在research.html。首页金额图表保留34只全观察池口径，状态和资金特征采用26只候选池，不混入8只A500对照候选。

## 特征定义

| 类别 | 计算 | 缺失处理 |
|---|---|---|
| 强度 | 当日净申赎÷（前日总份额×前日净值）；池层面先各自加总分子、分母后相除；1/5/10/20日z | 官方来源、前日规模与当日流量不全则留空 |
| 广度 | 净流入只数/可计算只数；类别金额正负方向 | 同时列可计算/应有样本与类别数 |
| 结构 | 大盘/小盘与成长/其他，分别占所有正流量之和及负流量绝对值之和 | 缺候选或某侧金额为0时该侧占比留空 |
| 逆势 | 中证全指当日、3日收盘收益与距60日收盘高点回撤 | 连续交易日行情缺失不填补 |
| 持续 | 连续入/出日数；5日和20日资金率均值及两者之差 | 零流量、缺失或成员变化中断计数；不用近零均值作除数 |
| 背景 | 收盘/250日收盘均值−1；20个对数日收益的样本标准差×√252 | 最少250个连续收盘，波动率需21个连续收盘 |
| 对照 | 当日可使用的至少3只已审查代理资金率中位数；与候选率原始差 | 遵循证据可得日；不是回归残差或国家队金额 |

公式中的ETF总资产是公开份额对应的资产规模，不是特定持有人的市值。5/10/20日“累计相对流量”是每日资金率的加总，不是收益率、份额增长率或资金复利收益。

大盘为沪深300、上证50；小盘与成长为中证1000、创业板、科创50；中证500及其余归为其他。不是统一指数公司的风格分类，组间ETF底层股票可能重叠；此处比较ETF申赎渠道，不把相加规模解释为不重复的底层股票风险敞口。

## 标准化与历史分位

同规模时，假设60日净申购均值10亿元、样本标准差20亿元，今天50亿元的z=(50−10)/20=2；若标准差40亿元，z=1。实际先做规模标准化，再减此前60日均值、除以样本标准差（ddof=1）。公式参考[NIST](https://www.itl.nist.gov/div898/software/dataplot/refman2/auxillar/standard.htm)。

1日基准不含当日。对h=5/10/20，当前窗口为t−h+1至t，基准为结束于t−h−59至t−h的60个同期限历史累计窗口；基准与当前窗口没有重合日期，基准窗口彼此仍重叠。所有值须来自完整且相同的候选成员，使用交易日历补齐缺失交易日，不跳过空值拼接。历史不够60、成员变化、任一窗口缺失或标准差≤1e−12时z留空。

经验分位=基准60个值中小于或等于当前值的比例，保留为独立字段。资金流不必正态，z=2不自动对应固定尾部概率；正净流入也可能有负z。重叠、序列相关、厚尾及多重比较使这些z值不能当作已校准显著性或交易成功率。

## 状态规则（按先后顺序）

1. 候选覆盖、此前60日基准或相邻行情不足：报告相应证据不足。
2. 正流量、z≥2、指数当日下跌、流入占比≥2/3：下跌中的广泛流入，标为托底形态，主体未确认。
3. 负流量、z≤−2、指数当日上涨、流入占比≤1/3且净流出占比≥2/3：上涨中的广泛流出，标为控速形态，主体未确认。
4. 其余|z|≥2：资金强度偏离常态。
5. 连续至少3日正/负流量：连续净流入/净流出。
6. 其余：常态区间观察。

规则未经独立样本、事件研究、控制行情后的增量收益或交易成本检验。这里不校准仓位比例、买卖价、收益预测与身份概率。国家队在大跌后参与导致的内生性和信号提前交易/衰减问题尚未通过描述性特征解决。

## 可复核产物

- features_daily.csv：逐交易日的候选池和逐只候选特征，空值保持为空，不以0代替。
- features_latest.json：当前池、26只候选、覆盖数、窗口样本数、状态及自然语言摘要。
- manifest.json：文件摘要、行数、输入与特征代码指纹。

当前输出仍是latest_revised，pit_eligible=false。即使滚动计算只用此前日期，也不代表已取得历史时点首次发布的输入；不能直接当作严格时点策略回测集。
